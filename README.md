### How to run:
On Eclipse: 
1. Click File, Import, Existing Projects into Workspace, toggle Select root directory, and select the downloaded folder
2. Expand the project folder, then src
3. Right click on flashchain, and select Run As, Java Application
4. For the test suite, right click on flashchain, and select Run As, JUnit Test
